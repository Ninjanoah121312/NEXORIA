NEXORIA — Privacy Policy

NEXORIA stores bot configuration, module settings, tickets, logging data, incident history, and other enabled feature data locally on the bot host. Some data is retained so features continue to work if the bot is restarted, a user logs out, or the bot is removed from a server.

Removing the bot from a server does not automatically erase that server's stored module data. Re-adding the bot can therefore restore the data that was previously stored for that server.

Connected profile information may also remain stored locally after an account is disconnected so historical records and previously configured features can continue to reference it.

OAuth client secrets, bot tokens, and API keys remain server-side and are not published to GitHub Pages. Do not publish your config.env file.

If you have a concern about retained data or do not agree with this storage model, please open a ticket in the NEXORIA support Discord server.
