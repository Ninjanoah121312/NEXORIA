Privacy Policy

NEXORIA data handling · Last updated September 29, 2026

This policy explains what information NEXORIA can store when you use the website, Discord bot, dashboard, and enabled modules. The exact data stored depends on the features you configure.

1. Information NEXORIA may store

Depending on the features you use, NEXORIA may store Discord identifiers and profile information needed to operate the dashboard, server configuration, tickets, logging records, incident history, custom commands, variables, and other enabled feature data. Data needed for a feature may remain available after a restart so the feature can continue operating.

2. Server and module data

Removing the bot from a server does not necessarily erase previously stored module data. Re-adding the bot can therefore allow previously retained configuration to be restored. Server owners can contact NEXORIA support about data retention or removal questions.

3. Credentials and secrets

Bot tokens, OAuth client secrets, API keys, and other private credentials are intended to remain on the bot host and must never be published in the website bundle or committed to a public repository. Do not expose config.env or similar secret files.

4. AI features

NEXORIA's documentation assistant uses the published NEXORIA documentation bundle in the website and does not call an external AI model or require an AI-provider API key. Conversation storage can be local to the bot host when you are signed in, or browser-local when the bot is unavailable.

5. Your choices

You can choose which NEXORIA features to enable and which servers the bot can access. For requests concerning retained data, privacy questions, or corrections, contact NEXORIA support.

6. Third parties

Discord and other services integrated with NEXORIA have their own privacy policies and terms. Their handling of information is governed by their respective services when you interact with them.

7. Changes

This policy may be updated when NEXORIA's data handling changes. The date above identifies the currently published version.
